# Hinge 3.0.0 — customer release notes

What buyers receive for the Gumroad direct-download purchase of Hinge 3.0.0. This document is the customer-facing product truth. Historical development-preview validation remains in [V3-PREVIEW.md](V3-PREVIEW.md).

## What you get

A notarized macOS app archive (`Hinge-3.0.0.zip`) built with Developer ID signing, Apple notarization, and stapling via `scripts/package-release.sh`. After purchase you download the ZIP, open `Hinge.app`, and optionally drag it into Applications.

Included features:

- Five lid-reactive effects: Duo, Roll, Shutter, Flex, and Iris.
- Subtle, Cinematic, and Crisp motion presets.
- Named local presets (save, rename, delete) and working-angle calibration.
- Native Effects, Motion, Automation, and Setup & Help workspace.
- Menu-bar quick controls, light and dark appearance, Esc / ⌃⌥⌘F pause.
- Battery Saver, Balanced, and Smooth performance modes.
- Optional automatic pause for chosen foreground apps or a connected external display.
- Guided setup, optional launch at login, and local diagnostics export.
- Generated-artwork preview and replay that work without Screen Recording.
- Local processing only: no account, analytics, or network license check.

This is a direct-download purchase. No paid license keys or DRM are implemented.

## Requirements

- macOS 14 or later.
- Apple silicon MacBook.
- A compatible lid-angle sensor for automatic lid-reactive effects.
- Screen Recording permission to animate your real desktop (frames stay in memory; audio is never captured).

Seller: replace `[VERIFIED_HARDWARE_LIST]` in [GUMROAD.md](GUMROAD.md) with models you personally verified with this Hinge build before taking payment. Do not treat upstream MacDuo hardware claims as Hinge verification.

## Limitations (state these honestly)

- Automatic effects animate the built-in display only. External displays are not animated.
- Screen Recording is required for live desktop animation. Without it, preview and replay still work on generated artwork.
- Lid-sensor compatibility varies by MacBook model and firmware. If the sensor is unavailable, preview and manual controls still work; automatic lid-driven desktop effects do not.
- Launch at login does not enable desktop capture. Capture starts only when the user enables Hinge.
- Battery impact and frame pacing depend on performance mode, display, and workload; unit tests do not prove battery savings on hardware.
